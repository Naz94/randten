# RANDTEN

A moderated, privacy-preserving South African marketplace.

**R10 to list. No commission.**

Core product principle: **Private from other users, accountable to the platform.**

Initial listing lifecycle:

`draft -> pending_payment -> pending_review -> approved -> published`

Side paths include payment failure, rejection, appeals, suspension, reinstatement, and permanent removal.

This repository is the source of truth for the RANDTEN application.
